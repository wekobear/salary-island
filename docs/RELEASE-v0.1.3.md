# 薪动日常 v0.1.3 · 心动钱包

- 新增「心动钱包」应用图标：薄荷绿钱包、金色爱心扣和跳动线条。
- 设置页、欢迎页与关于页统一使用新 Logo，适配 macOS 多种图标尺寸。
- 保留设置页左下角的退出入口、下班倒计时、收入估算及快乐目标。
- 升级沿用现有薪酬和作息配置。

## 下载与安装

适用于 Apple Silicon Mac。下载 **SalaryDaily-v0.1.3-macOS.zip**，解压后将「薪动日常.app」拖入「应用程序」，双击打开。升级前先退出旧版本。

首次使用可点击「播放奶茶演示」体验，再填写自己的月薪与作息。

**SalaryDaily-v0.1.3-source.zip** 是对应版本源码；**SHA256SUMS.txt** 提供文件校验值。

## 首次打开遇到弹窗

如果出现“未打开‘薪动日常’”的提示，从本仓库下载并确认来源可靠后，可按以下步骤操作：

1. 点击首次弹窗中的 **「完成」**。
2. 打开 **系统设置 → 隐私与安全性**，在「安全性」区域找到「薪动日常」，点击 **「仍要打开」**。
3. 在新的确认弹窗中再次点击 **「仍要打开」**；如需验证身份，按系统提示完成。
