# 薪动日常 v0.1.5 · 薪酬即时更新

- 同一工作时区内，保存月薪和作息后立即重算今天的收入、全天预计收入、工资速率与倒计时。
- 更新今天已过去的计薪时间，历史日期的记录保持不变。
- 保留已有奖励记录，新的达成静默记录，避免重复提示。
- 替换旧的待生效计划；重启后保留新结果，保存失败不会改变生效金额。
- 设置预览明确提示「保存后立即生效」，跨时区变更按预览时刻切换。

## 下载与安装

适用于 Apple Silicon Mac。下载 **SalaryDaily-v0.1.5-macOS.zip**，解压后将「薪动日常.app」拖入「应用程序」，双击打开。升级前先退出旧版本。

首次使用可点击「播放奶茶演示」体验，再填写自己的月薪与作息。

**SalaryDaily-v0.1.5-source.zip** 是对应版本源码；**SHA256SUMS.txt** 提供文件校验值。

## 首次打开遇到弹窗

如果出现“未打开‘薪动日常’”的提示，从本仓库下载并确认来源可靠后，可按以下步骤操作：

1. 点击首次弹窗中的 **「完成」**。
2. 打开 **系统设置 → 隐私与安全性**，在「安全性」区域找到「薪动日常」，点击 **「仍要打开」**。
3. 在新的确认弹窗中再次点击 **「仍要打开」**；如需验证身份，按系统提示完成。
