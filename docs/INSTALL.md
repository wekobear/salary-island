# 薪动日常安装与首次打开

从[本仓库 Releases](https://github.com/wekobear/salary-island/releases)下载安装包，解压后将「薪动日常.app」拖入「应用程序」，双击打开。升级前先退出旧版本。

首次打开如果出现下面的提示，先别慌，可以按这 3 步操作。以下步骤适用于从本仓库下载、且你确认来源可靠的「薪动日常」。

## 1. 在首次弹窗中点击「完成」

看到“未打开‘薪动日常’”的提示时，点击「完成」关闭弹窗。

<img src="images/install-01-warning.png" width="360" alt="首次打开提示未打开薪动日常，点击左下角的完成按钮">

## 2. 前往「系统设置 → 隐私与安全性」

向下找到「安全性」区域，在“已阻止‘薪动日常’以保护 Mac”这一行点击「仍要打开」。

<img src="images/install-02-privacy-security.png" width="800" alt="系统设置的隐私与安全性页面，在薪动日常被阻止的提示右侧点击仍要打开">

## 3. 在新的确认弹窗中再次点击「仍要打开」

在“打开‘薪动日常’？”弹窗中，点击红框标出的「仍要打开」。如果系统要求验证身份，按提示输入 Mac 登录密码或使用触控 ID。

<img src="images/install-03-open-anyway.png" width="360" alt="打开薪动日常的确认弹窗，点击中间红框里的仍要打开按钮">

完成后即可打开应用。点击「播放奶茶演示」先看效果，或填写月薪与作息，开始查看下班倒计时和收入估算。
