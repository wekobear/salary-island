# 薪动日常 v0.1.6 · 目标文案更直白

- 将「约需 X 个相同班次」改为「约合 X 天工资」。
- 表示目标价格相当于多少天的工资，不代表还需工作的天数或已累计存款。
- 保留 v0.1.5 的薪酬即时更新功能。

## 下载与安装

适用于 Apple Silicon Mac。下载 **SalaryDaily-v0.1.6-macOS.zip**，解压后将「薪动日常.app」拖入「应用程序」，双击打开。升级前先退出旧版本。

首次使用可点击「播放奶茶演示」体验，再填写自己的月薪与作息。

**SalaryDaily-v0.1.6-source.zip** 是对应版本源码；**SHA256SUMS.txt** 提供文件校验值。

## 首次打开遇到弹窗

如果出现“未打开‘薪动日常’”的提示，从本仓库下载并确认来源可靠后，可按以下步骤操作：

1. 点击首次弹窗中的 **「完成」**。
2. 打开 **系统设置 → 隐私与安全性**，在「安全性」区域找到「薪动日常」，点击 **「仍要打开」**。
3. 在新的确认弹窗中再次点击 **「仍要打开」**；如需验证身份，按系统提示完成。
