## 安全检查

- 薪酬模块无网络请求、AI调用、分析SDK或账号；针对新增目录检索未见工资日志输出。没有对整款上游应用作“零网络”承诺，原音乐等可选模块仍可能联网。
- 独立 bundle ID `local.salaryisland.preview`；薪酬JSON位于该应用沙盒，目录0700、文件0600，原子写入。文件为本地明文，未宣称加密；同一登录用户仍可读取。
- 上游自动更新源移除，更新检查默认停止、入口禁用；独立文件架路径与XPC标识，防止与原 Boring Notch 混用数据。
- 首次薪酬流程未观察到相机、日历、辅助功能授权弹窗；音乐控制按用户打开音乐页延迟初始化。保留上游可选模块 entitlements，其权限仍由系统管理，不等于已授权。
- GPL-3.0 与原作者声明保留，交付对应源码。本地签名不等于 Developer ID 或公证；尚未公开发布。
- 测试月薪为虚构数据，交付前已移出应用数据目录；用户打开看到空白首次设置。

## 当前限制与下一轮

首版支持同一天内班次；节假日和调休需手动填，系统专注状态用手动“安静到下班”。富豪对比、统计平均工资库、跨日储蓄目标、发薪日留后续。

尚未验证：无刘海/外接屏切换、Spaces/全屏组合、真实锁屏睡眠、VoiceOver全流程、Reduced Motion实机表现、CPU/能耗基线、跨时区旅行与日期回拨组合、macOS 14/15兼容。跨时区生效需要进一步检查日期边界，暂不作为经过验收的场景。公开试用前补这些检查与分发签名/公证。
