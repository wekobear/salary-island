# 薪动日常 · 运营推广初稿

2026-10-20；GitHub 首页已有产品介绍和下载入口。以下招募、验证与投放仍为草案。

## 一句话

“下班倒计时在走，奶茶钱也在到账。”界面持续标“估算收入”，避免让用户误解为真实银行到账。

## 第一支演示

20秒屏幕录制：设置虚构月薪 → 灵动岛每秒增长 → 奶茶目标达成 → 一键隐私 → 下班倒计时。全程标演示数据，不录入用户真实工资。文案候选：“工位上每过去一秒，生活里就多一点甜。”

## 小范围验证

按 PRD 先邀请5–8位自愿试用者，用5个工作日观察：是否2分钟内独立完成设置、是否理解估算口径、哪句文案开心/尴尬、提示是否打扰、第5天是否愿意继续开。计划门槛为80%完成设置、80%理解口径、70%愿意保留；均未产生实际数据。

通过手工匿名反馈收集，不采集工资或自动上传行为。先依据反馈调整语气和频率，再决定是否公开发布。公开版本另做兼容/能耗检查、GPL源码交付与签名公证，不将本地体验包称为正式上线。


## GitHub 首页演示素材（2026-10-21）

首页只展示内置虚构演示数据截图。旧操作录屏从当前源码移除，不进入新源码交付包。

## 即时更新体验（2026-10-21）

新行为的演示应展示「修改月薪 → 预览 → 保存并立即更新 → 今日金额与速率同步变化」。不再宣传修改后需要等到次日；历史记录和同日奖励去重保留。跨时区按预览时刻切换。


## 大件累计进度（2026-10-23，本地开发）

演示可新增「小目标按天达成，大件一点点接近」：用虚构数据展示昨天进度保留、今天继续增加和达成后的反馈。统一标注“累计估算工资”，不把各目标相加成真实存款。此功能已在本地 v0.1.7 实现，尚未推送新安装包或执行推广。


## 心动钱包演示候选（2026-10-23，本地试做）

可用内置外观预览展示空钱包→半满→装满，再展示收起态的同款小钱包。文案候选：“今天的努力，让钱包一点点鼓起来。”演示金额一律使用虚构值，主钱包为每日估算进度，大件跨天累计另行展示。当前不发布素材或执行推广。
