# 薪动岛 v0.1.0 · 第一版体验包

基于 Boring Notch 改造；先体验，再继续打磨。

## 已包含

- 灵动岛下班倒计时、今日估算收入、秒/分/小时工资。
- 奶茶、午饭、衣服等自定义快乐目标，最多5项。
- 温柔 / 抽象 / 嘴替语气，隐私遮盖、手动安静。
- 作息和午休、排班例外、变更预览、日快照与成就去重。
- 自填薪资参考、奶茶演示，以及原音乐/文件架入口。

## 使用

下载 macOS.zip，解压后打开 SalaryIsland.app。先点“播放奶茶演示”，或填写自己的月薪与作息，再将鼠标移到屏幕顶部展开。

当前包为 Apple Silicon、macOS 14+ 的本地 ad-hoc 签名体验版，实际测试为 macOS 26 内置刘海屏；尚未完成公开分发签名与公证。此包不包含个人工资和本机配置。

## 验证与边界

51项计算与调度检查通过；构建、嵌套签名、保存后重启、隐私遮盖及奶茶反馈已验证。外接屏、长时能耗、完整辅助功能和跨时区组合仍待验证。金额是估算，不是银行到账；夜班、富豪对比、统计平均工资库等不在本版。
