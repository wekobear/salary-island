# 薪动日常

**下班倒计时在走，奶茶钱也在到账。**

一款陪你上班的 macOS 灵动岛小工具。把月薪换算成每秒、每分钟、每小时的收入，看着时间变成奶茶、好饭和一件喜欢的衣服。

[下载 v0.1.6 体验版](https://github.com/wekobear/salary-island/releases/tag/v0.1.6) · [安装图解](docs/INSTALL.md) · [使用与构建说明](README-SalaryIsland.md)

`main` 源码已更新到 **v0.1.8 build 13**，新增跨天累计目标与心动钱包。当前可下载安装包为 v0.1.6；体验这些新功能可按[构建说明](README-SalaryIsland.md#构建与检查)运行主干源码。

## 它会陪你做什么

- **等下班**：紧凑和展开状态都把倒计时放在左边，收入放在右边。
- **看工资增长**：展示今日估算收入，以及每秒、每分钟、每小时的收入速率。
- **领一点快乐**：自定义最多 5 项目标，奶茶等每日目标按天计算，扫地机器人等大件目标跨天累计，展示累计进度与剩余金额。达成时给一句短反馈，倒计时和金额保持可见。
- **看钱包鼓起来**：薄荷绿钱包随今日进度逐渐饱满，展开和收起态同步；点击钱包可查看五档外观与完整演示。
- **选择陪伴方式**：温柔、抽象、嘴替三种语气；眼睛隐藏收入和目标，铃铛让提示安静到下班，点击都有状态提示。
- **按自己的作息来**：支持工作日、上下班、午休、临时休息和补班；保存前预览日薪、时薪与生效时间。

## 开始使用

1. 在 [Releases](https://github.com/wekobear/salary-island/releases/tag/v0.1.6) 下载 `SalaryDaily-v0.1.6-macOS.zip`，解压后将「薪动日常.app」拖入「应用程序」，双击打开。
2. 点击「播放奶茶演示」先看效果，或填写月薪与作息，预览后保存。
3. 把鼠标移到屏幕顶部灵动岛，查看倒计时、今日收入和下一份小快乐。
4. 点击顶部齿轮打开设置，左下角可「退出薪动日常」；关闭设置窗口只会收起设置。

当前体验包适用于 **Apple Silicon、macOS 14+**，已在 macOS 26 内置刘海屏验证。升级沿用原配置，无需重新填写月薪。

收入是按计划作息折算的**估算值**，不连接银行；目标独立比较，不扣除收入，也不代表已经消费。薪酬数据保存在本机，无需账号。首版支持同一天内的班次，节假日与调休需手动设置。

## 版本与开发

主干 v0.1.8 build 13 包含大件目标跨天累计、今日收入驱动的钱包形变，以及针对 22pt 收起态独立绘制的小钱包。保存月薪与作息后仍立即更新今日收入、日薪、时薪和倒计时；历史记录保留，奖励不重复提示。

可下载安装包 v0.1.6 将目标提示改为「约合 X 天工资」，暂未包含上述主干新增功能。
